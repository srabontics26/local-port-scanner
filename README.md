# Local Port Scanner

A small Python tool for checking common network ports on a local or authorized host.

## Features

- Checks selected TCP ports
- Shows which ports are open
- Uses Python socket connections
- Intended for local or authorized security testing

## Requirements

- Python 3

## Usage

Run the script and enter a hostname or IP address when prompted.

## Disclaimer

Use this tool only on systems you own or have permission to test.
